# SKILLMATCH JS

## Sobre o projeto
    o Skillmatch.js possibilita a comparação do perfil de candidato FrontEnd junior com as necessidades de cada vaga FE entre níveis (junior, pleno, senior) e compatibilidade por comparação das skills técnicas de ambas as partes, por meio de:
    - cálculo de porcentagem comparativa estabelecendo níveis de aderência do candidato à vaga, por meio de scores.
    - identificação das skills do candidato exigidas pelas vagas, em um nível individualizado (1 candidato x 1 vaga), mas também de forma geral sobre o conjunto das vagas.
    - identificação das habilidades faltantes ao candidato para uma correspondência ideal às respectivas vagas.   
    - identificação das 4 vagas mais compatíveis da listagem de vagas analisadas.
    - identificação de conceitos e tecnologias recomendadas para o plano de estudo do candidato, visando sua qualificação profissional

## Objetivo
    o projeto Skillmatch.js foi a oportunidade de treinar, aplicar e consolidar os conceitos estudados em aula durante o módulo 01:
    Foram usados: variáveis, arrays, loops de repetição forEach e for, if/else, prompt-sync, functions e arrow functions, classes e herança, objetos e atributos, métodos de        array .push(), .filter(), .includes(), .sort(), .join() e console.log
    
## Como executar
    Este projeto foi desenvolvido em ambiente Node.js. devido à decisão prática de priorizar a interação entre o usuário e o terminal para a visualização da execução.
    Portanto a instalação de Node.js e npm, com seus arquivos e dependencies decorrentes, são essenciais.
    .gitignore devidamente criado e configurado.
